I want to create a tool to help me as a developer to review code in the era of agentic LLMs.

The stack and design should be based on ../video-studio.

The objective of this tool is  to review code generated by LLM agents more easily and with more control.

The main features are:
- A diff mode to see just the changed code
- A tag system to tag what regions were reviewed, the entire current dif region can be tagged or just a section
- The tag system should support tag some parts to be reviewed with care later in the end
- Fuzzy search to find files
- Cross references checking, so when analyzing a given class, function, etc, i can find where it is used and i can navigate to the file if i want to
- The diff mode is the default, but a project mode should exists, the project mode will behave like a normal IDE, it will allow to navigate through all the files independent of what was changed, the project mode will not allow to tag regions as reviewed, but it should allow to tag to be reviwed with care (for this concept introduce a short good name)

The interface of this project is very very important, it should use vim motions and behave much like magit (emacs package).
